# 🧮 Simple Calculator

A **Simple Calculator** built using **HTML**, **CSS**, and **JavaScript**.  
It performs basic arithmetic operations like addition, subtraction, multiplication, and division with a clean and responsive UI.

---

## 🚀 Features

- Perform **basic arithmetic operations** (+, −, ×, ÷)  
- **Responsive design** that works on both desktop and mobile  
- **Clear and Delete** functionalities  
- Simple and easy-to-understand code (great for beginners)  
- Instant calculation without page reload  



---

## 🛠️ Technologies Used

- **HTML5** – for the structure  
- **CSS3** – for styling and layout  
- **JavaScript (ES6)** – for functionality and logic
